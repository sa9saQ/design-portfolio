## 制作物

### AI 確定申告アプリ — モバイル UI プロトタイプ
個人事業主向けの確定申告アプリ。レシートを撮影すると AI が勘定科目を自動分類する体験を中心に、「不安を安心に変える」をコンセプトとして申告フロー全体を設計。

- **画面数**: 14 (ホーム / 収入 / 経費 / 控除 / 確認 / 提出完了 / マイページ / 動線図 / 入力シート 2 / 状態画面 4)
- **特徴**: AI レシート自動分類の演出、累進課税の透明な計算内訳、赤を使わない優しいエラー設計、30〜60 代向けの読みやすさ (コントラスト比 4.5:1 以上 / 文字 12px 以上)
- **配色**: 深い森緑 + 琥珀色アクセント + クリーム背景
- **フォント**: Noto Sans JP / Plus Jakarta Sans
- **制作プロセス**: Claude Design で骨子生成 → 人の判断で読みやすさ・動線・エラー状態を反復改善

▶ [プロトタイプを見る](./ai-tax-app/)

## 制作の考え方

- AI で速く作り、人が品質をコントロールする
- ユーザーが「迷わない・不安にならない」動線を最優先
- 失敗・空・エラーの状態こそ丁寧に設計する
